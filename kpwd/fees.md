# Registration Fees and Renewal Rules

## Registration Fees

| Class     | Registration Fee |
| --------- | ---------------- |
| 1st Class | ₹25,000          |
| 2nd Class | ₹15,000          |
| 3rd Class | ₹9,000           |
| 4th Class | ₹6,000           |

### Additional Fees
- QR License Fee: ₹1,000
- Welfare/CBF Fee: ₹1,000

## Renewal Rules
If renewal is delayed:
- **Within 1 year**: Double fee penalty
- **1–2 years**: Triple fee penalty
- **Beyond 2 years**: License cancellation possible
